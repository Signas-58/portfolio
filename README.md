## ⚡ Key Highlights & Features

1. **Dual-Theme Engine (Recruiter Mode Toggle)**
   - **Dev / AI HUD Mode (Default):** Deep obsidian black (`#030712`), neon cyan glow accents (`#00f3ff`), subtle zero-gravity particle dust, and terminal telemetry.
   - **Recruiter Mode:** Ultra-clean, high-contrast light slate theme designed for HR and talent acquisition managers to review qualifications, CV, and core competencies instantly.

2. **Zero-Gravity Levitation (Framer Motion)**
   - Interactive floating tech badges (Python, Next.js, SQL, Cybersecurity, Linux, AI, Kubernetes) utilizing sine-wave physics loops.

3. **Featured Engineering Case Studies**
   - **FRIDAY AI Assistant:** Voice-activated intelligent automation engine (Python, Local LLM routing, speech synthesis).
   - **DzidzaAI:** Multilingual offline-first learning platform for Zimbabwean primary schools (SQLite local caching, low-connectivity architecture).
   - **Campus Safety Alert System:** Real-time incident reporting and role escalation blueprint for Midlands State University.
   - **Banking Operations & POS Analytics Dashboard:** Transaction throughput, error spike modeling, and merchant POS terminal telemetry.
   - **Cybersecurity & Kubernetes Ops:** Container service monitoring, defensive security labs, and automated fault recovery.

4. **"My AI Lab" — FRIDAY Terminal Sandbox**
   - Interactive terminal preview allowing recruiters and visitors to query verified information regarding Tsakane's background, Metbank experience, and stack with built-in guardrails and rate-limiting.

5. **Live Developer Dashboard**
   - Telemetry linked with GitHub profile [`@Signas-58`](https://github.com/Signas-58) showing public repositories, active contributions, and language distribution.

6. **Interactive Curriculum Vitae & Print Support**
   - In-browser full CV preview modal with native print/PDF export capability.

## 🚀 Getting Started

### Prerequisites
- Node.js `v20.0.0` or later
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/Signas-58/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the portfolio.

### Production Build

```bash
npm run build
npm run start
```
